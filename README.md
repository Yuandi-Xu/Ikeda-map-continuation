# Ikeda map: MATLAB plotting examples

MATLAB plotting scripts and figure data accompanying “Matrix-free numerical continuation of the Ikeda map in passive Kerr resonators.”

`Fig2/`, `Fig3/`, `Fig4/`, and `FigS1/` contain the scripts and data for each figure.

Run `plot_all_figures` to display all four figures, or run `plot_Fig*.m` in its own folder.
