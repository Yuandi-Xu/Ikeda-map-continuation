# Fig3

HSS, Turing-pattern and cavity-soliton branches, CS profiles and Floquet multipliers.

Each CS spectrum contains 512 multipliers. Gray, blue and red circles show
background-dominated, stable localized and unstable modes; blue diamonds mark
the translational neutral multiplier.

Run `plot_Fig3.m` in MATLAB. Data: `Fig3_data.mat`.
SVG/PNG files are reference figures.
